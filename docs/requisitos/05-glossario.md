# 5. Glossário

| Termo | Significado |
|---|---|
| **Organização** | A empresa cliente do MUNTU (um ginásio ou uma cadeia). Unidade de isolamento dos dados. |
| **Filial** | Uma instalação física da organização, com caixa, equipa e catracas próprios. |
| **Zona** | Parte de uma filial (musculação, cardio, sala de aulas, piscina, balneários). |
| **Membro** | Cliente do ginásio que treina. Pode ter conta na app. |
| **Plano** | Oferta comercial: preço, periodicidade, âmbito e horário. |
| **Subscrição** | Um plano contratado por um membro, com início, fim e estado. |
| **Âmbito** | Onde um plano dá acesso: local, rede, híbrido, por zona/horário. |
| **Check-in / entrada** | Registo de acesso de um membro a uma filial (validado, recusado ou manual). |
| **Anti-passback** | Regra que impede o mesmo membro de entrar duas vezes seguidas ou em dois locais ao mesmo tempo. |
| **Lotação** | Pessoas dentro da filial agora, calculada pelos check-ins. |
| **Turno** | Período de trabalho com um caixa e um responsável (ex.: manhã 06–14). |
| **Caixa** | O dinheiro físico de um turno, com fundo de troco, movimentos e fecho. |
| **Fundo de troco** | Valor inicial em dinheiro no caixa. |
| **Sangria** | Retirada de dinheiro do caixa para o cofre. |
| **Reforço** | Entrada de dinheiro no caixa para troco. |
| **Fecho cego** | Contagem do caixa sem ver o valor esperado; a diferença aparece no fim. |
| **Passagem de turno** | Entrega do caixa, pagamentos e pendências ao turno seguinte, com conferência. |
| **Divergência** | Diferença entre o contado e o esperado, registada sem apagar dados. |
| **Livro razão** | Registo imutável de todos os movimentos de dinheiro. |
| **Estorno** | Movimento inverso que corrige outro, com motivo e aprovação. |
| **Aprovação** | Pedido de autorização para uma acção sensível ou acima do limite do perfil. |
| **Pendência** | Assunto por resolver que passa de turno em turno (cobrança, documento, reclamação, reserva, ocorrência). |
| **Ocorrência** | Problema reportado no ginásio (equipamento, limpeza, segurança, atendimento, lesão…). |
| **FR / FT / NC** | Factura-recibo, factura e nota de crédito. |
| **Série** | Sequência de numeração de documentos fiscais (por filial e ano). |
| **SAF-T (AO)** | Ficheiro normalizado de exportação de dados fiscais para a AGT. |
| **AGT** | Administração Geral Tributária de Angola. |
| **Multicaixa Express** | Pagamento móvel da rede Multicaixa (EMIS), por pedido no telemóvel do cliente. |
| **Referência Multicaixa** | Pagamento por entidade + referência em ATM ou homebanking. |
| **TPA** | Terminal de pagamento automático (cartão). |
| **Receita perdida** | Dinheiro que o ginásio deveria ter recebido e não recebeu (atrasos, sessões pagas e não dadas, acessos sem pagamento). |
| **Fuga** | Padrão suspeito de perda (subscrições sem pagamento, estornos acima da média, movimentos fora de horas). |
| **Rede MUNTU** | Rede de ginásios de donos diferentes com acesso cruzado e liquidação mensal. |
| **Liquidação** | Acerto mensal de contas entre ginásios da rede. |
